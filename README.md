## Descripción

Caso Práctico Migracion tienda en linea

Se cuenta con un sistema desplegado en producción el cual es la base de la tienda en línea de la compañía.

El equipo de desarrollo ha identificado serios cuellos de botella operativos debido a que los principales módulos de la plataforma (carrito de compras, catálogo de productos, órdenes, inventario y pasarela de pagos) comparten una misma base de código legacy, esquemas de persistencia, dependencias de red y de compilación en Maven. 

Se desea migrar este sistema legado a una arquitectura moderna sin interrumpir la operación diaria del sistema así como tener la capacidad de implementar nuevas funcionalidades.
